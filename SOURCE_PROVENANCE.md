# Source snapshot provenance

This local release draft is a working-tree snapshot of commit
`646ec99d80e39bcccd1eb60ac95cbc685027a33e` from the team's private
`bcn-gradient-depression` repository. It intentionally does not include that
repository's history or local data. The original repository and its history
remain intact. This public snapshot is not evidence that the reproduction requirements
have been met.

The competition starter and challenge materials retain their stated upstream
notices and licenses. See `LICENSE`, `CITATION.cff`, `RULES.md`, and `DATA.md`.

The four `evaluation/results/baseline_*.csv` files and their README match the
Git blob IDs published by the official challenge repository at commit
`f8f2629ff1e0985f81d7e59d8413678514ee1530`:
<https://github.com/metrica-sports/more-than-a-hack-2027/tree/f8f2629ff1e0985f81d7e59d8413678514ee1530/evaluation/results>.
These are the organisers' public baseline files, not this team's submissions.
